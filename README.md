# DB-CLI: Примитивная база данных

Легковесная утилита для управления структурами данных в командной строке. Позволяет создавать, просматривать и удалять таблицы в интерактивном режиме.

## 📋 Возможности

### Общие команды
| Команда | Описание |
|:---|:---|
|`exit`| Закрывает программу. |
|`help`| Показывает справочную информацию по доступным командам. |

### Управление таблицами
| Команда | Описание | Синтаксис |
|:---|:---|:---|
|`create_table`| Создает новую таблицу с указанными столбцами и их типами. | `create_table <имя> <столбец1:тип> ...`|
|`list_tables`| Выводит список всех существующих таблиц. | `list_tables`|
|`drop_table`| Удаляет указанную таблицу и все её данные. | `drop_table <имя>`|

## 📝 Примечания

*   **Поддерживаемые типы данных**:
    *   `int` — целые числа (например, `age:int`).
    *   `str` — строки (например, `name:str`).
    *   `bool` — логические значения (например, `is_active:bool`).
*   **Автоматический ID**: Если при создании таблицы не указан столбец с именем `ID`, система автоматически добавит первую колонку с именем `ID` и типом `int`.
*   **Синтаксис**: Типы данных указываются после двоеточия в названии столбца (формат `имя:тип`).
*   **Уникальность**: Имена таблиц должны быть уникальными. Попытка создать таблицу с существующим именем приведет к ошибке.
*   **Безопасность**: Команда `drop_table` необратима. Все данные в удаляемой таблице будут потеряны безвозвратно.
